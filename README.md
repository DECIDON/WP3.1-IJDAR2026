# WP3.1-ijdar26
Code and experiments for the IJDAR 2026 paper on NER & textual rigidity

## Layout

- `data/` – datasets (inputs) used in the experiments
- `src/` – reusable code (models, metrics, utilities)
- `experiments/` – scripts/notebooks that run each experiment
- `results/` – outputs (tables, figures, logs) reported in the paper
